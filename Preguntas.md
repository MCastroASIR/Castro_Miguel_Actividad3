# Preguntas
**1. ¿Qué diferencia existe entre los comandos `git add`y `git commit`?**

El comando `git add` sirve para seleccionar los archivos que queremos incluir en el proximo registro (commit).
El comando `git commit` guarda definitivamente esos cambio en el historial del repositorio.

**2. ¿Qué información proporciona el comando `git diff`antes de registrar una modificación?**

El comando `git diff` nos muestra las diferencias entre la ultima versión registrada y la que tenemos preparada antes de guardarla.

**3. ¿Qué ventajas ofrece Git frente a guardar manualmente diferentes versiones de un archivo, como *guia_v1.md*, *guia_v2.md* o *guia_final_md*?**

Nos permite realizar un seguimiento de las diferentes versiones, compararlas fácilmente, optimizar el espacio al no tener varias copias del mismo archivo y permite que varias personas trabajen en un mismo proyecto.
